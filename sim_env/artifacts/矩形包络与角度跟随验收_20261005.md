# 矩形包络、速度上限与角度跟随验收

## 实现范围

平地、静态障碍、前视 D435i 和 UWB 跟随。当前执行链路为：有效 UWB 世界位置 → 局部舒适跟随区域 → 已知历史滚动地图上的位置/朝向搜索 → Nav2 MPPI 跟踪 → 加速度平滑与完整矩形制动检查 → 原 ONNX 步态 → MuJoCo。

默认身份保持 `rate / annulus / cone / steady / process`。没有开启轨迹意图 `trail` 或相机几何观察 `camera` 实验来替换默认方案，也没有加入低速死区或起步补偿。

| 配置 | 当前值与用途 |
|---|---|
| 前进命令上限 | 0.8 m/s；搜索导航、MPPI 与仿真接收端一致 |
| 转向命令上限 | ±1.0 rad/s；实际模型跟踪能力另列 |
| 机身 | 中心位于 `base_footprint` 的长0.70、宽0.32 m矩形 |
| 滚动地图 | 121×121，0.10 m；未知不可行驶 |
| 姿态搜索 | 8个朝向、前进边与原地转向边；检查完整机身及旋转扫角 |
| MPPI | DiffDrive，30 Hz，800条采样，2.4 s预测窗口 |
| 观察速度 | ≤0.45 m/s，观察停点另留0.10 m平面漂移余量 |
| 行走角度 | 对齐路径；方向偏差0.15 rad后增加软代价，没有方位超限硬停转规则 |
| 停人看向 | 人稳定0.4 s后，偏差0.12 rad进入、0.06 rad退出；整段转身安全才执行 |

## 为什么这样判断可通行

不再用0.48 m圆和约0.55 m中心净空阈值判断通行。`footprint.py` 按连续位置和朝向计算矩形与闭栅格方盒相交，包含内部、边界接触和格角接触。平移检查全部扫过的区域，旋转用带误差上界的区间包络覆盖中途角点，窗口外及未知接触均拒绝。

绿色栅格仅表示**至少一个离散朝向**容得下矩形，不能当作当前朝向安全，也不能证明能在这里转身。路径的前进、转向、简化、返回后的接入以及制动保护均另作几何验证。观察阶段也复用矩形校验，删除了重复的中心距离硬门槛；有回归用例证明含漂移余量的矩形能在0.60 m通道保持观察状态。

实际姿态不一定恰好落在格中心或八个离散方向上。当前加入连续起点连接：直接接入可达格，或者先沿当前朝向前移到有转向空间处，再接入离散搜索。所有连接均完整检查，既不把未知写成自由，也不使用人的路线证明可通行。八方向图仍是离散近似，不能据此保证所有实际可走通道都会规划出来。

## 两个停顿根因及修正

第一，矩形可以以实测姿态站在窄通道中，但最近格中心没有可接入的离散朝向。旧搜索返回 `NO_REACHABLE_RECTANGLE_POSE` 并在第二个障碍附近卡住。连续起点连接恢复了已知通道中的前移接入；失败地图保存为 `tests/fixtures/rectangle-connector-consecutive-20261005.json`，回归测试检查真实地图不变、全路线矩形安全且取得前进。

第二，直线距离环包含“与人隔着已知墙”的位置。人在两道交错墙之间转弯时，终点先被拉到墙近侧的横向位置，随后又移回通道方向，机器人反复转向。现在距离带候选到人的连线若接触已知占据格，就不作为完成跟随的终点，改沿已知通道推进。使用闭格线段求交，未知不被虚构为墙或自由区域。

独立连续障碍对照中，仅起点连接版完成任务但平均vx约0.266 m/s、低速17.0%、最大间距4.44 m，流畅性失败；加入隔墙终点修正后约0.367 m/s、低速5.4%，原门槛通过。这些试验原始报告各自保留，最终成绩必须使用同一源码的整轮复测。

## 角度究竟跟随谁

行走时，机身对齐安全路径的前视方向；绕障期间机身与人的方位不同是正常现象。界面同时显示机身世界朝向、人与机身的方位、剩余路径方向、请求/实测转速及误差。原始UWB世界方位另有诊断值及采样时间；单个标签只能给出人的位置，不能测量人体自身朝向。

人停在舒适距离内时，进入 `FACING` 安全看向；前进候选固定为零，仍经过矩形转身与残余运动制动检查。没有完整已知转身空间、目标失效或深度失效时停车。人重新走动则退出看向，重新由通道路径引导。没有为对准人而中断半途绕障。

## 指令上限与模型能力

独立原模型能力基准见 [请求上限能力数据](execution-requested-limits-20261005.json)。原地请求±1.0 rad/s时，正/反转稳态约+0.443/−0.621 rad/s；同时请求vx=0.8时，约+0.786/−0.744 rad/s，实际vx约0.738/0.732 m/s。模型输入几乎持续饱和，两个用例 `nominal_tracking_met=false`。基准退出码0仅代表姿态与停车检查通过，**不代表准确跟踪1.0 rad/s**。

本轮允许使用用户指定的0.8/1.0指令边界，但没有扩大原训练模型输入范围。这是仿真执行能力限制，不能据此判断Go2实机Sport接口的能力。

## 当前边界与下一步

当前仿真仍使用真值里程计、理想深度和简化UWB噪声，静态历史地图不能证明盲侧没有动态闯入障碍。尚未接入实机CAPO/VIO、RK3588计算资源测量、真实相机/标签安装外参和NLOS数据。上述测试不能替代这些验收。

下一步首先固定源码，重复不同初始角度、目标速度和障碍间距的测试，评价成功率及停顿分布；再依据实测执行能力改善转弯响应与路线连续性，随后接入真实时间戳/TF链路和RK3588资源测试。先验证本轮效果，不继续用放松未知区域或缩小碰撞包络来换取速度。
